📖 Guía de uso de MILITOPO

×

🎯 ¿Qué es MILITOPO?

MILITOPO es una herramienta profesional para diseñar recorridos topográficos de campo. Organiza los puntos de control en módulos y genera recorridos equilibrados para competiciones o ejercicios tácticos. Cada módulo contiene un conjunto de puntos (balizas), y cada recorrido pasará por un punto de cada módulo, siguiendo un orden estricto.

Nomenclatura de los puntos: Cada punto se identifica como P12.
- P = punto
- 1 = número del módulo
- 2 = número de punto dentro de ese módulo
Ejemplo: P32 es el punto 2 del módulo 3.

📦 Paso 1: Configurar la estructura

Define la arquitectura del ejercicio:

  • Módulos – número de estaciones o controles (ej. 8 módulos).
  • Puntos por módulo – cuántas balizas distintas tendrá cada módulo (ej. 5 puntos).
  • Coordenadas – elige entre formato UTM (ej. 30T 450000 4780000) o MGRS (ej. 30S XJ 12345 12345).

Al confirmar, se generarán automáticamente ejemplos para cada punto que podrás editar.

📍 Paso 2: Editar puntos topográficos

Puedes introducir las coordenadas de cada punto de tres maneras:

  • Automático con mapa IGN: pulsa el botón "Mapa topográfico y aéreo IGN". Se abrirá un mapa interactivo con capas topográfica y aérea (cambiables con el botón superior).
    - Selecciona el punto que quieres modificar en el desplegable.
    - Haz clic en el mapa en la ubicación exacta → aparecerá un marcador temporal con la coordenada.
    - Confirma la asignación y se creará una chincheta permanente con el nombre del punto (P11, P12…).
    - Puedes arrastrar cualquier chincheta a una nueva posición; se te preguntará si quieres mover el punto.
    - Haz clic en una chincheta para ver sus coordenadas y un botón para eliminar el punto.
  • Manual: escribe directamente las coordenadas en los campos de texto de cada punto (en la tabla desplegable). El formato debe coincidir con el sistema elegido en el paso 1.
  • Subir GeoTIFF: carga tu propio plano georreferenciado. Se mostrará la imagen y podrás hacer clic para obtener las coordenadas nativas del raster (en su sistema de proyección).

Utiliza los botones "🔄 RESTABLECER EJEMPLOS" para volver a la configuración inicial y "✓ VERIFICAR COMPLETITUD" para asegurarte de que todos los puntos tienen coordenadas y descripción.

🗂️ Paso 3: Generar recorridos

Elige el número de recorridos que deseas generar (hasta 100). El sistema distribuirá los puntos de cada módulo de forma equilibrada para que cada punto aparezca la misma cantidad de veces (o con una diferencia mínima). Además, evita que dos recorridos tengan la misma combinación de puntos consecutivos, aumentando la variedad.

El número total de puntos por recorrido es igual al número de módulos que hayas seleccionado. Por ejemplo, si has configurado 8 módulos, cada recorrido tendrá 8 puntos (uno de cada módulo).

Al pulsar "✨ GENERAR ZIP", se descargará un archivo comprimido con tres carpetas:

  • Organizadores/ – contiene dos archivos Excel: uno con todos los recorridos (códigos asignados) y otro para anotar resultados.
  • Balizas/ – un archivo Excel por cada punto con la lista de recorridos que pasan por él, el siguiente punto y el código secreto.
  • Hojas_Recorrido/ – una hoja por cada recorrido para que los participantes marquen su paso, con las balizas en orden y espacio para anotar los códigos.
